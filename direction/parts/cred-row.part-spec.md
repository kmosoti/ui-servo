# Part: cred-row

Read `_conventions.md` first. A single quiet row of credential chips
directly under the hero.

Content, verbatim from the prototype (facts, not copy — do not compress):

- B.S. Software Engineering — UT Arlington
- Splunk Certified Admin
- Splunk Power User
- Cribl Certified User
- AWS Certified Solutions Architect — Associate

Rules:

- **Vendor names are allowed here and only here** (owner ruling,
  2026-08-08): a certification's name is a fact about the credential, not
  tool-dropping. This is the carve-out from the hero's no-vendor rule; the
  carve-out does not travel to any other part.
- These are inert chips: muted text, hairline border, no interaction, no
  `data-tag` — credentials are not part of the tag vocabulary and must not
  light up when a skill tag is selected.
- One row, wrapping. No icons, no logos, no links.
- The part must read as *quieter* than the hero above it and the telemetry
  strip below it. If it competes, it is wrong.
