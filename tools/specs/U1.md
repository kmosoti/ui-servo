# U1 — Evidence: domain models, store port, JSONL adapter

Owned paths: `ui_servo/domain/evidence.py`, `ui_servo/ports/__init__.py`, `ui_servo/ports/store.py`, `ui_servo/adapters/__init__.py`, `ui_servo/adapters/jsonl_store.py`, `tests/test_evidence.py`.

## Deliverables

1. **ui_servo/domain/evidence.py** (pure; stdlib + pydantic only): the evidence *stock* the control loops read.
   - `Signal` — one observation: `span_id: str`, `turn_id: str`, `source: SignalSource` (enum-ish literal: `"probe" | "harness" | "gate" | "judge"`), `kind: str` (e.g. "swap-error", "unknown-class", "overflow", "animation", "axe-violation", "verdict"), `ts` (ISO str), `payload: dict` (full verbose data, untruncated).
   - `SpanEvidence` — all signals joined for one span; `TurnEvidence` — spans for a turn; pure join/filter functions (`join_spans(signals) -> dict[str, SpanEvidence]`, `failures_only(...)`, `by_kind(...)`).
   - Severity derivation is POLICY, not evidence — do not classify here beyond `kind`.
2. **ui_servo/ports/store.py**: `EvidenceStorePort` Protocol — `append(signal)`, `append_many(signals)`, `signals_for_turn(turn_id)`, `signals_for_span(span_id)`; `ExemplarStorePort` Protocol — `save_exemplar(name, files: dict[str, bytes], meta: dict)`, `list_exemplars()`.
3. **ui_servo/adapters/jsonl_store.py**: orjson JSONL implementation; one file per turn under a root dir (`evidence/<turn_id>.jsonl`); append-only, crash-safe (write line + flush); exemplar store writes `exemplars/<name>/` files + `meta.json`.
4. **tests/test_evidence.py**: domain join semantics; adapter round-trip (tmp_path); property: appending N signals then reading yields N with order preserved; domain module imports checked pure (no ui_servo.adapters/ports/control, no orjson — orjson belongs to the adapter only).

## Acceptance

- `uv run pytest tests/test_architecture.py -q` (dependency rule still green)
