# U10 — Fast loop: style vector + blandness + regulator

Owned paths: `ui_servo/domain/variant.py` (Variant + StyleVector parts; MAP-Elites grid arrives in U11 — leave a clear seam), `ui_servo/control/regulator.py`, `tests/test_regulator.py`, `tests/fixtures/blandness/` (generic-template HTML/computed-style fixtures + one styled-per-direction fixture). READ: U0 contract, U1 evidence, U2 sanitizer port, U5 sensor port.

## Deliverables

1. **domain/variant.py**: `Variant` (id, part, html, builder_family, cell hint); `StyleVector` — deterministic embedding of a rendered fragment from computed-style samples + screenshot statistics: OKLCH histogram bins (8 hue × 3 lightness), spacing-value distribution (normalized to contract scale hits/misses), border-radius distribution, type-size distribution, contrast ratio stats. Input = a `StyleSample` dict (produced by the playwright sensor's page.evaluate; document the exact shape here and keep extraction JS in the adapter). `distance(a, b) -> float` (cosine); `blandness(vector, anti_corpus: list[StyleVector]) -> float` = min distance to corpus (LOW = bland).
2. **control/regulator.py**: the fast homeostatic loop for one variant: sanitize (port) → serve/observe (sensor port) → collect signals → evaluate hard gates. Hard gates (each boolean, each a `GateResult`): sanitizer accepted; no swap-error/js-error/csp signals; no unknown-class; no overflow; no motion-violation; axe violations empty (wcag2aa); reduced_motion_ok. Output `RegulatorReport` (variant_id, gates: list[GateResult], passed: bool, style_vector, blandness_score, evidence_span). **Taste separation invariant**: gates and blandness/taste live in different fields; `passed` is gates-only — enforced by construction and asserted in tests.
3. **tests**: with stubbed sanitizer/sensor ports — gate failure paths each trip `passed=False` with the right gate named; style vectors: generic-template fixture yields LOWER blandness distance (i.e., more bland) than the styled fixture against a 3-template anti-corpus; gates never appear in any taste/score field.
