# U12 — Gauntlet orchestration: skill + agent definitions

Owned paths: `.claude/skills/gauntlet/SKILL.md`, `.claude/agents/builder.md`, `.claude/agents/critic.md`, `.claude/agents/integrator.md`.

## Deliverables

1. **SKILL.md** (frontmatter: name `gauntlet`, description triggering on "/gauntlet <mission>" usage): the orchestration protocol for the lead Claude Code session:
   - Mission intake: restate mission; the bar = `direction/direction.toml` + `direction/references/` + `exemplars/`.
   - Decomposition: THE AGENT decomposes into smallest independently-buildable-and-judgeable parts (fragments); records part specs.
   - Build: spawn builder subagents (`.claude/agents/builder.md`), one per part, isolated contexts, parallel when independent; builders receive direction + exemplars + part spec only.
   - Deterministic gauntlet: run `uv run python -m ui_servo.control.servo --parts <...>` to gate variants (classes 0–2) BEFORE any critic call; broken variants go back to builders with gate evidence (this costs no critic tokens).
   - Critique: survivors go to the blind panel (`ui_servo.control.critique` via servo) — pairwise vs bar, per-axis rubric, selector-citing findings; the skill NEVER shows critics builder reasoning.
   - Revision loop: largest-gap findings → same builder; fresh critics next round (rotation is enforced by the code; the skill must not reuse critic transcripts).
   - Integration: `.claude/agents/integrator.md` subagent reviews the assembled page for cross-part consistency.
   - Termination: bar passed / round budget (default 3) / no-strategy-change repeated failure / human brake. Escalate 2-of-3 panel disagreement to the human with both screenshots.
   - Human picks from the frontier report → `exemplars/` (the only injection of real taste).
2. **builder.md**: role = actuator; receives direction contract, exemplars, part spec; outputs fragment HTML honoring the fragment-authoring contract (allowlist classes, data-span-id root, motion via tokens, reduced-motion safe); explicitly forbidden from judging its own output or seeing critic identities.
3. **critic.md**: role = comparator; hostile, context-blind — receives ONLY part spec + artifact (screenshots/aria/evidence) + the bar; compares side-by-side against references; names the largest meaningful gap with selector citations; forbidden from seeing builder reasoning or prior critiques.
4. **integrator.md**: whole-artifact consistency reviewer (rhythm, spacing coherence, voice), fresh context.

All three agent files: valid frontmatter (name, description, tools if restricted), concise role prompts embodying the Gauntlet invariants.
