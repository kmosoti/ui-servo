# U13 — servo: one full gauntlet round, composed over the ports

Owned paths: `ui_servo/control/servo.py`, `tests/test_servo.py`. READ everything; MODIFY nothing else.

## Deliverables

1. **control/servo.py**: composition root + CLI. `run_round(variants: list[Variant], *, contract, stores, sanitizer, sensor, judges, round_id, out_dir) -> RoundResult`:
   1. regulator pass on every variant (fast loop, parallel via threads is fine — sensors are I/O bound),
   2. gate-failed variants → `RoundResult.rejected` with their evidence (these NEVER reach judges),
   3. survivors → pairwise tournament via critique (round-robin or single-elimination for K≤6; document choice) with policy rotation/blindness,
   4. escalations collected; ranked survivors → explore.admit; frontier report written,
   5. `RoundResult` (rejected, ranked, escalations, report_path, archive coverage) serialized to evidence store + stdout summary.
   - CLI: `python -m ui_servo.control.servo --candidates <dir-of-html-fragments> --part hero --round 1 --out evidence/rounds/1/` — builds Variants from files. Filename grammar (ORCHESTRATOR RULING, authoritative): `<part>.<family>.<k>.html` (k = variant index, e.g. `hero.claude.2.html`); the two-token legacy `<part>.<family>.html` is accepted as k=0. builder_family = second token. Critic-facing artifacts MUST be blind-staged: servo copies candidate screenshots/html under opaque names (`<out>/blind/<part>.<A|B>.<hash>.*`) and judges only ever receive those paths — original family-bearing paths never reach a judge prompt. Wires real adapters (jsonl store, nh3, playwright sensor, three CLI judges). `--dry-judges` flag swaps judges for stubs (deterministic ranking by blandness) so the pipeline is testable without live model calls.
2. **tests/test_servo.py**: end-to-end with stub ports + 2 fixture variants (one gate-broken, one clean): broken lands in rejected with named gate, clean gets ranked, report file exists, evidence store contains signals from every stage. CLI smoke with `--dry-judges` against fixture candidates dir.
