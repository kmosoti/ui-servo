# U2 — Pre-ship comparator: sanitizer port + nh3 adapter + attribute schema

Owned paths: `ui_servo/ports/sanitizer.py`, `ui_servo/adapters/nh3_sanitizer.py`, `tests/test_sanitizer.py`, `tests/fixtures/fragments/` (clean + seeded-bad HTML fixtures). You may READ `ui_servo/domain/contract.py` (U0) for the allowlist/motion-table API — do not modify it; if you need an additional pure helper there, define it in your own module instead.

## Deliverables

1. **ui_servo/ports/sanitizer.py**: `SanitizeResult` (accepted: bool, cleaned_html: str | None, violations: list[Violation]; Violation = kind + detail + selector-ish locator) and `SanitizerPort` Protocol: `check(fragment_html: str) -> SanitizeResult`. This is latency-class-0: rejects before anything renders.
2. **ui_servo/adapters/nh3_sanitizer.py**: composition of three checks, all reported (don't stop at first):
   - **nh3** (Rust ammonia) sanitize with a tag/attribute policy for htmx hypermedia: allow standard flow/phrasing content, `hx-*` attributes, `data-*` (incl. data-span-id), `aria-*`, `class`, `id`, `style` DISALLOWED (style goes through tokens.css), no `script`/`iframe`/event handlers. Violation when nh3's output differs structurally from input (something was stripped).
   - **class allowlist**: every class in `class="..."` must be in the allowlist (seed from `DirectionContract.class_allowlist_seed()` + an optional extra-classes set passed to the adapter constructor). Handle escaped variant selectors by normalizing CSS escapes (e.g. `hover\:x` → `hover:x`) when the allowlist is later fed from parsed stylesheets (tinycss2 helper included for parsing a CSS file into class names).
   - **attribute schema**: pydantic-validated constraints for htmx attrs (hx-get/post/put/delete/patch URLs must be same-origin relative paths; hx-swap ∈ documented set; hx-trigger syntax sanity) and required `data-span-id` on the fragment root.
3. **tests**: seeded XSS (`<img onerror>`, script tag, javascript: URL), unknown class, bad hx-swap value, missing span id → each rejected with the right violation kind; clean fixture passes and round-trips.
