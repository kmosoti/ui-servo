# U3 — Browser sensor runtime: probe/probe.js

Owned paths: `probe/probe.js`, `probe/README.md`, `tests/fixtures/probe.html`. You may READ `direction/direction.toml` + `ui_servo/domain/contract.py` to understand the motion-table shape the server will inject.

## Deliverables

**probe/probe.js** — vanilla JS, no deps, IIFE. Size budget (orchestrator ruling, final): `gzip -n -9 -c probe/probe.js | wc -c` ≤ 5632 bytes on the readable committed source, measured number stated in the header with that exact command. The probe ships only in the dev loop; if it ever ships to production, add a minification step (comment-stripped source already measures ≤4 kB gz). Configured via `window.__UI_SERVO__ = {beacon: "/beacon", motion: {durations: [...], easings: [...], properties: [...]}, turnId: "..."}` injected by the server.

Checks (each emits `{spanId, turnId, kind, ts, payload}` into a batch):
1. htmx integration: `htmx:afterSwap` (kind "swap-ok", target span id, elt tag/id), `htmx:responseError`/`htmx:sendError` (kind "swap-error", status, path).
2. Custom elements: monkeypatch-free — listen for a `ui-servo:ce-error` CustomEvent convention documented in probe/README.md, plus wrap `customElements.define` to catch connectedCallback throws (try/catch shim). WASM: capture `WebAssembly.instantiate*` rejections by wrapping, and a documented panic-hook event (`ui-servo:wasm-panic`).
3. PerformanceObserver: `longtask`, `layout-shift` (with value + sources' node names), `event` (interaction latency > 100ms), `element` timing entries for swapped roots (server adds `elementtiming` attr).
4. Motion conformance: on each afterSwap, `document.getAnimations({subtree:true})` scoped to the swapped element; for each animation read computed duration/easing/keyframe properties; compare against `__UI_SERVO__.motion`; off-token → kind "motion-violation" with the offending values; conforming → kind "animation" (evidence, not violation).
5. CSSOM class check: at boot build `Set` of class names from `document.styleSheets` (guard cross-origin with try/catch; normalize CSS escapes for variant selectors like `hover\:`); after each swap, unknown classes in the swapped subtree → kind "unknown-class".
6. Overflow probe: after swap (rAF-deferred), `scrollWidth > clientWidth` on swapped subtree elements and `document.scrollingElement` → kind "overflow" with measurements.
7. Errors: `window.onerror`, `unhandledrejection`, `securitypolicyviolation` → kinds "js-error"/"rejection"/"csp".

Batching: queue events; flush via `navigator.sendBeacon(cfg.beacon, JSON.stringify(batch))` on `visibilitychange→hidden`, every 2s when non-empty, and immediately for error-class kinds. Span id: nearest `[data-span-id]` ancestor (or the swapped target's own).

**tests/fixtures/probe.html**: standalone page (no htmx dependency required — synthesize htmx-like CustomEvents) that deterministically triggers at least: swap-ok, unknown-class, overflow, motion-violation, js-error. Used by U4's Playwright acceptance.
