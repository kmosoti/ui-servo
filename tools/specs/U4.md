# U4 — Driving adapter: preview server + beacon ingest

Owned paths: `ui_servo/adapters/beacon_ingest/` (router module), `ui_servo/adapters/preview_server.py`, `tests/test_preview_server.py`. READ (not modify): `ui_servo/domain/evidence.py`, `ui_servo/ports/store.py`, `ui_servo/adapters/jsonl_store.py` (U1), `probe/probe.js` + `tests/fixtures/probe.html` (U3), `ui_servo/domain/contract.py` (U0).

## Deliverables

1. **preview_server.py**: FastAPI app factory `create_app(candidates_dir: Path, store: EvidenceStorePort, contract: DirectionContract, turn_id: str, dev: bool = True)`:
   - `GET /candidate/{name}` → serves candidate fragment wrapped in a minimal shell (tokens.css inline, probe.js + `window.__UI_SERVO__` config injected when dev; motion table from `contract.motion_table()`).
   - `GET /fixture` → serves tests/fixtures/probe.html through the same shell (for sensor verification).
   - `GET /assets/probe.js`, `GET /assets/tokens.css`.
   - Mounts beacon router. `uvicorn` runnable: `python -m ui_servo.adapters.preview_server --candidates <dir> --port 8700`.
2. **beacon_ingest/**: `POST /beacon` accepting sendBeacon payloads (text/plain or application/json body — sendBeacon sends without content-type reliably; parse defensively with orjson); each event → `Signal` (validate kinds; unknown kinds accepted with kind preserved — sensors may evolve) → `store.append_many`. Respond 204 fast (hot path: no model, no heavy work).
3. **tests/test_preview_server.py**: FastAPI TestClient — beacon batch lands in a tmp jsonl store with correct span/turn ids; candidate route injects probe + config when dev, omits when not; **Playwright integration test** (chromium, headless): serve the fixture via uvicorn on an ephemeral port, load `/fixture`, wait for beacons, assert the store received at least kinds {swap-ok, unknown-class, overflow, motion-violation, js-error} — this closes U3's acceptance too. Mark playwright test with `@pytest.mark.playwright` and skip cleanly if browsers are missing (but they ARE installed in this repo's env — `uv run playwright install chromium` was part of setup; if not yet, run it).

## Acceptance

- `uv run pytest tests/test_preview_server.py -q` (all tests incl. playwright one pass)
- `uv run pytest tests/test_architecture.py -q`
