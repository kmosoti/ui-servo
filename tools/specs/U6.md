# U6 — The product skeleton: site/ (axum + maud + htmx)

Owned paths: `site/` (Cargo.toml, src/, templates note below, assets/), plus `.gitignore` additions for `site/target/`. You may READ `direction/direction.toml` and run `uv run python -m ui_servo.domain.contract --emit-css site/assets/tokens.css` to generate tokens (commit the generated file — it's a build artifact the gauntlet regenerates).

## Deliverables

Rust stable (1.97), cargo project `site/`:
1. **Cargo.toml**: axum 0.8, tokio (rt-multi-thread, macros, signal), maud (axum feature), tower-http (fs, trace), tracing + tracing-subscriber. No template files on disk — maud = compile-time HTML in Rust (put page fns in `src/pages/`, fragment fns in `src/fragments/` — these fragment fns are the gauntlet's unit of work).
2. **src/main.rs**: axum app; routes `/`, `/projects`, `/writing`, `/about` (SSR shell pages with placeholder content honoring the direction tokens), `/fragments/:name` returning fragment HTML for htmx swaps, static `/assets/*` (tokens.css, probe.js copied or symlinked from ../probe at dev), graceful shutdown on SIGTERM.
3. **Shell layout** (`src/layout.rs`): semantic HTML5, skip-link, `<meta name="color-scheme">`, htmx script tag vendored locally (`assets/htmx.min.js` — download at build setup, record version), tokens.css link, and when env `UI_SERVO_DEV=1`: inject `probe.js` + `window.__UI_SERVO__` config (beacon URL http://localhost:8700/beacon, motion table values read at startup from `site/assets/motion.json` — also emitted by the contract CLI; add `--emit-motion-json` support NOT by editing domain/contract.py (not owned) but by a tiny `site/build.rs`-free approach: generate motion.json with `uv run python -c` in your setup and commit it; document regeneration in site/README.md).
4. **Every fragment root** carries `data-span-id` (server-generated ULID-ish per render) — the join key for the whole sensor stack.
5. **Reduced-motion**: tokens.css consumers must include an `@media (prefers-reduced-motion: reduce)` block zeroing animation durations; put the base rule in `site/assets/site.css` (hand-written minimal css using ONLY custom properties from tokens.css).
6. **site/README.md**: run instructions, regeneration commands, fragment-authoring contract (allowed classes = allowlist, span-id required, motion via tokens only).

## Acceptance

- `cd site && cargo build 2>&1 | tail -3` clean
- `cargo run` (background) then `curl -s localhost:8080/ | grep -q data-span-id` and all four routes return 200; kill server.
