# U8 — Judge port + CLI adapters (cross-family, no API keys)

Owned paths: `ui_servo/ports/judge.py`, `ui_servo/adapters/cli_judges.py`, `tests/test_cli_judges.py`. READ: U0 contract, U1 evidence.

## Deliverables

1. **ports/judge.py**: `JudgeRequest` (prompt: str, image_paths: list[Path], response_schema: dict | None, timeout_s: int), `JudgeResponse` (family: str, raw: str, parsed: dict | None, rc: int, duration_s: float), `JudgePort` Protocol: `judge(request) -> JudgeResponse`; `family` property. Families are the *variety source* for the panel (requisite variety) — document that.
2. **adapters/cli_judges.py**: three implementations shelling to locally-authenticated CLIs (absolute paths, subprocess timeouts):
   - `ClaudeJudge`: `~/.local/bin/claude -p <prompt> --output-format json` — images referenced by absolute path IN the prompt text (claude reads local files when asked to). Parse the result JSON envelope; extract text; if response_schema given, instruct JSON-only output and parse defensively (orjson; strip code fences).
   - `CodexJudge`: `~/.codex/packages/standalone/current/codex exec -s read-only --skip-git-repo-check -o <tmp> <prompt>`; with response_schema → `--output-schema <tmpfile>`. Images by absolute path in prompt.
   - `GeminiJudge`: agy-bridge HTTP `POST localhost:4401/prompt` (bearer from `~/.config/agy-bridge/token`, httpx) parsing the NDJSON stream for the final `{"event":"result"...}` line; fallback subprocess `~/.local/bin/agy -p` if bridge is down. Images by absolute path in prompt.
   - Shared: JSON-extraction helper (find outermost {...} / strip fences), one retry on schema-parse failure with an explicit "return ONLY valid JSON matching schema" re-ask, full request/response recorded as a `Signal` (source "judge") when a store is provided.
3. **tests/test_cli_judges.py**: unit tests with monkeypatched subprocess/httpx (no live calls): envelope parsing per family, schema re-ask path, timeout → JudgeResponse rc!=0 not exception. PLUS one `@pytest.mark.live` smoke (skippable via env UI_SERVO_LIVE=1 gate): each family answers `{"ping": "pong"}` against a trivial schema — run it once in acceptance.

## Acceptance

- `uv run pytest tests/test_cli_judges.py -q`
- `UI_SERVO_LIVE=1 uv run pytest tests/test_cli_judges.py -q -m live` (all three families return parsed JSON)
- `uv run pytest tests/test_architecture.py -q`
