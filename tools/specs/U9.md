# U9 — Critique protocol: verdict domain + policy rules + slow-loop service

Owned paths: `ui_servo/domain/verdict.py`, `ui_servo/domain/policy.py`, `ui_servo/control/__init__.py`, `ui_servo/control/critique.py`, `tests/test_critique.py`. READ: U8 judge port, U1 evidence, U0 contract.

## Deliverables

1. **domain/verdict.py** (pure): `RubricAxis` literal set {hierarchy, typography, color, motion, density, direction_conformance, distinctiveness}; `Finding` (axis, selector: str REQUIRED, gap: str, severity: {"major","minor"}); `PairwiseVerdict` (winner: {"A","B","tie"}, per_axis: dict[axis, {"A","B","tie"}], findings: list[Finding], confidence); JSON schema constant for judge response_schema derivation.
2. **domain/policy.py** (pure): the comparator governance rules as functions —
   - `eligible_judges(builder_family, judge_families) -> list` (self-preference guard: builder family excluded),
   - `rotate(judges, round_id) -> list` (deterministic rotation; a judge never re-judges a pair it saw in a previous round — track by (judge, pair_key) history),
   - `derandomize(verdict, was_flipped) -> PairwiseVerdict` (A/B order randomization is applied at ask-time; this maps answers back),
   - `panel_outcome(verdicts) -> {"winner"|"escalate", detail}` (2-of-3 majority; disagreement or missing majority → escalate),
   - `validate_verdict(dict) -> PairwiseVerdict | list[str]` (selector-citation required on every finding; missing → violation list for the re-ask).
3. **control/critique.py**: orchestrates one pairwise panel round over JudgePort instances: builds the blind prompt (part spec + the bar: direction summary + reference names + screenshots of A and B by path; NEVER builder reasoning), applies order randomization per judge (seeded RNG from round_id for reproducibility), one re-ask on invalid verdict, records everything as Signals, returns `panel_outcome`.
4. **tests**: stub JudgePort (canned JSON) — self-preference exclusion provable; flipped-order verdicts derandomized correctly; invalid verdict (finding w/o selector) triggers exactly one re-ask then hard-fails that judge; 2-1 majority wins; 1-1-1 escalates; rotation never repeats (judge, pair) across rounds.
